# Mission Control Architecture

## What it is
Web-based control plane for managing OpenClaw gateways, agents, channels, boards, and tasks.
Gives operators a single UI for work orchestration, approval-driven governance, and real-time agent visibility.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend language | Python 3.12+ |
| Backend framework | FastAPI 0.131 |
| ORM | SQLModel (SQLAlchemy 2.0 + Pydantic) |
| Database | PostgreSQL 16 (async via psycopg 3) |
| Migrations | Alembic |
| Auth | Clerk JWT **or** local bearer token (configurable) |
| Queue | RQ 2.6 + Redis 7 |
| Real-time | SSE (sse-starlette) + WebSocket client (websockets 16) |
| Crypto | `cryptography` 45 (RSA device identity for gateway auth) |
| Frontend framework | Next.js 16 (App Router), React 19 |
| Styling | Tailwind CSS 3 + Radix UI |
| State | TanStack React Query 5 |
| Tables | TanStack React Table 8 |
| API client | Orval (auto-generated from OpenAPI — **never edit `src/api/generated/` by hand**) |
| Icons | Lucide React |
| Type checking | mypy --strict (backend), TypeScript strict (frontend) |
| Testing | pytest-asyncio (backend), Vitest + Cypress (frontend) |

## Key Patterns

### Backend
- **FastAPI dependency injection** everywhere: `get_session`, `require_org_member`, `require_org_admin`, `get_board_for_user_write`
- **Async-first**: all DB and HTTP ops are `async`
- **Multi-org tenancy**: row-level isolation via `organization_id`
- **Activity audit log**: every state mutation creates an `ActivityEvent` record
- **RQ background jobs**: webhook dispatch, async side effects
- **After any model change**: run `alembic revision --autogenerate -m "..."` then `alembic upgrade head`
- **After any API change**: run `make api-gen` to regenerate the frontend client (backend must be at `127.0.0.1:8000`)

### Frontend
- **Never edit `frontend/src/api/generated/`** — it's auto-generated by Orval
- **React Query** for server state (queries + mutations)
- **Atomic design**: atoms → molecules → organisms → templates → pages
- Use `DashboardPageLayout` for new pages (handles sidebar, header, sign-in gate, admin-only notice)
- SSE streams use exponential backoff reconnection via `createExponentialBackoff` from `@/lib/backoff`

## Environment Variables (key ones)

From `backend/.env.example`:
- `AUTH_MODE` — `local` or `clerk`
- `LOCAL_AUTH_TOKEN` — 50+ char bearer token for local auth mode
- `DATABASE_URL` — PostgreSQL connection string
- `OPENCLAW_GATEWAY_*` — gateway connection settings (URL, token, min version)

## Dev Commands

```bash
# Full stack (Docker)
docker compose up --build -d

# Local loop (faster iteration)
docker compose up -d db redis
cd backend && uv run uvicorn app.main:app --reload --port 8000
cd frontend && npm run dev

# After backend API changes
make api-gen   # regenerates frontend/src/api/generated/

# Run checks
make check     # lint + typecheck + tests + frontend build
```
